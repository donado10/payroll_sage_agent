# The Sage agent project book

## Summary

The long-form reference for this repository: what the agent is made of, how it runs here, and what
each script proves. More detailed than `.claude/rules/`; less authoritative than the code, which
always wins — and, for anything exchanged with the platform, less authoritative than `platform/`.

## Conventions in these pages

- Every chapter opens with a `## Summary` paragraph.
- Paths and identifiers are real and current. If one is wrong, the code is right — fix the page in
  the same change.
- **Built and planned are never mixed without saying which.** The agent is being built phase by
  phase (`platform/plan.md`); a page describing something not built yet says so in its first lines.
- Diagrams are Mermaid, inline. No image files.
- **No secret values, and no row of a client's Sage database, ever.**
